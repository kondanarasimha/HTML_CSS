## 📌 Rules for AI Agent

1. The user will share a **topic** and their **understanding** of it.
2. The agent must write it in a clean **Q&A format** (Question → Answer).
3. If the user's understanding is **wrong or incomplete**, the agent must **correct it** and write the accurate version.
4. Keep answers **clear, concise, conceptually and interview-ready**.
5. All notes are appended below under the **Notes** section.
6. Follow the **existing patterns** of how questions and answers are written in the Notes section.
7. Keep explanations **short and concise** — avoid unnecessarily long answers.
8. If the user doesn't specify a section, **automatically place** the Q&A under the most relevant section based on the topic. Create a **new section** if needed. When creating a new section, **also check all existing Q&As** — if any existing question belongs to the new section, **move it there automatically**. Always keep questions **organized under their correct section** and maintain proper numbering.
